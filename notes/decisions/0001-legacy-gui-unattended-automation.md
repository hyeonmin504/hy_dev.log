# 0001. 소스 없는 GUI 프로그램이 낀 수작업을 무인화하는 방식

날짜: 2026-09-29
상태: 채택됨
출처: log/2026/2026-09-29.md

## 맥락
매일 사람이 "외부 기관 데이터 수신 → 사내 DB 동기화 → 슬랙 보고"를 손으로 했다. 10분씩 손이 묶이고 빠뜨리기 쉬웠다. 무인화하려는데 제약이 셋이었다.

- 수신 프로그램은 외부 기관이 PowerBuilder로 만든 것이라 소스도 명령줄 옵션도 없다. 화면을 눌러야만 동작한다.
- 수신 서버와 두 DB는 사내망에서만 열린다.
- 실행 PC는 밖으로 들고 나가는 노트북이다. 서버가 아니다.

여기에 운영 요구가 하나 더 있었다. 슬랙 보고는 기존처럼 본인 이름으로, 리마인더 스레드에 답글로 달려야 한다.

## 선택지

| 축 | 선택지 | 결과 | 이유 |
|---|---|---|---|
| 수신 프로그램 구동 | 프로그램 수정 / API 요청 | 탈락 | 소스 없음, 공급사 수정 불가 |
| | 화면 자동 조작 | **채택** | 사람 조작을 그대로 재현. 컨트롤은 화면 고유 ID, 창 문구는 Win32로 직접 읽기 |
| 실행 일정 | 클라우드 루틴 | 탈락 | 사내망과 PC 화면이 필요 |
| | BIOS 예약 부팅 + 자동 로그인 | 탈락 | 설정 부담, 자동 로그인은 보안 문제 |
| | Windows 작업 스케줄러 | **채택** | 로그온 상태에서만, 놓친 회차는 다음 로그인 때 1회만 몰아서 |
| 비공개 레포 인증 | 배포 키 | 탈락 | 레포 관리자 권한 필요 |

| | 봇 토큰 | 탈락 | 본인 이름으로 안 올라감 |

| 빈도 | 1회/일 → 2회/일 | 거침 | |
| | 평일 09~18시 매시 (10회) | **채택** | 데이터 신선도 우선 |

## 결정
작업 스케줄러가 매시 스크립트를 띄우고, 스크립트는 두 DB에 실제 접속되는지로 사내망을 판별한 뒤에만 수신 프로그램을 조작한다. 되돌릴 수 없는 동작(기존 데이터 삭제 후 재수신)은 확인창 문구가 기대값과 일치할 때만 누른다. 이 가드가 테스트 중 실제로 한 번 잘못된 실행을 막았다.

비밀 정보는 Windows DPAPI로 이 PC·이 계정에서만 풀리게 저장한다.

## 결과
- 좋아지는 것: 사람 손 없이 평일 10회 실행, 결과가 슬랙 스레드에 본인 이름으로 보고됨. 노트북이 밖에 있으면 조용히 건너뜀.
- 감수하는 것: 매 회차 3분 30초 데이터 공백, 매시간 양쪽 서버 부하, 매시 정각 창이 떠서 작업 방해, 스레드 답글 하루 최대 10개, 노트북을 켜 두고 사내망에 둬야 함.
- 되돌리는 조건: 수신 프로그램에 명령줄이나 API가 생기면 화면 자동화를 버린다. 사내망 제약이 풀리면 서버로 옮기고 스케줄러 대신 클라우드 루틴으로 바꾼다.
