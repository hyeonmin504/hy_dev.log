# 2026-11-03

**요약**: 10월 말에 만든 Claude 데일리 브리핑(아침마다 한 장짜리 페이지 + 내 DM)을 「직접 만든 비서 3주 운영기」 기사와 비교해 개인 비서형으로 바꿨다. 핵심은 판단을 더 시키는 게 아니라 상태를 남기는 것이었다 — 내가 정한 「끝남·안 함」을 장부에 남기고, 어제와 달라진 것만 알리고, 못 읽은 건 어제 값으로 버틴다.

## 배경과 제약

10-22에 외부 Claude 비서 서비스 소식을 보고 "아침에 비서처럼 받아 보고 싶다"에서 시작했다. 스킬 하나가 슬랙·이슈 트래커·GitHub·git을 읽어 HTML 아티팩트 한 장을 같은 주소에 다시 발행하고, 평일 아침 클라우드 예약 실행으로 돈다. 상사 요청과 날짜 언급은 개인 레포의 마크다운 장부에 쌓고 실행 끝에 그 폴더만 커밋한다 — 비서의 기억이 곧 git 이다.

첫 2주 동안 고친 건 거의 다 판단이 아니라 배관이었다.
- 첫 페이지는 "한눈에 안 들어온다" → 할 일을 가장 크게 맨 위, 항목은 제목 한 줄 + 메타 한 줄로 고정
- 예약 실행 프롬프트가 슬랙 쓰기를 통째로 막아서 내 DM 요약이 안 갔다 → 내 DM 한 곳만 허용
- 클라우드 환경 네트워크가 기본(신뢰 도메인만)이라 공개 조회 API 도 DNS 실패 → 지난 값 유지로 대체
- 아티팩트는 이번 세션이 먼저 읽지 않은 버전에 덮어쓰면 발행이 거절됐다 → 발행 전 읽기를 절차에 넣음

## 기사와 비교해 보니

기사는 23회 실행, 실수 6건을 기록했고 "실수 대부분은 판단 오류보다 화면을 잘못 읽거나 상태를 잘못 관리한 데서 나왔다"고 했다. 내 브리핑에 대 보니 빈 곳이 그대로 보였다.

| 기사의 기법 | 내 브리핑의 상태 |
|---|---|
| 사람이 「끝남·안 함」을 정하고 비서는 「끝난 것 같다」까지만 | 할 일을 매번 처음부터 다시 만든다. 체크는 날짜별 브라우저 저장소에만 있어 다음 날 사라지고 비서는 읽지도 못한다 |
| 전날과 달라진 것만 알림, 반복은 「반복」 표시 | DM 이 매일 전체 요약 |

| 데이터는 JSON, 현황판은 고정 | HTML 을 매번 통째로 다시 쓰고, 태그 여닫기 개수를 세서 깨짐을 막고 있었다 |

## 막혔던 것

비교하면서 "장부 커밋이 10-23 이후로 없다, 예약 실행이 멈춘 것 같다"고 먼저 짚었다. 실제로는 로컬 레포가 원격보다 8커밋 뒤처져 있었을 뿐이고 실행은 매일 돌고 있었다. 기사가 말한 바로 그 실수 — 판단은 맞는데 **읽은 상태가 낡았던** 것 — 를 비교하는 도중에 내가 그대로 했다. 상태를 근거로 말하기 전에 원격 기준으로 맞추는 게 먼저다.

## 선택

- **결정 입력은 두 갈래.** 페이지의 체크·「안 함」 버튼은 아티팩트 DB 에 저장하고, 휴대폰에서는 DM 스레드에 `끝남 1 3` / `안 함 2 이유` 로 답글을 단다. 예약 실행 환경에서 아티팩트 DB 를 읽을 수 있는지 확인하지 못해서 DM 을 보조 경로로 같이 뒀다.
- **할 일 id 를 고정했다.** `출처 키-할 일 종류`(PR 번호+단계, 메시지 ts+종류). 날이 바뀌어도 같은 id 여야 「끝남」이 이어지고 「N일째」를 셀 수 있다.
- **오래 멈춤 기준은 5 근무일.** 기사는 오픈소스 기여라 14일(7일은 재촉이 잦았다고 함), 나는 팀 안의 리뷰·답변이라 1주로 잡았다. 재촉 초안은 페이지에만 쓰고 보내지 않는다.
- **비서는 끝났다고 단정하지 않는다.** PR 머지 같은 근거가 보여도 지우지 않고 「끝난 것 같음 · 근거」로만 표시한다.

## 결과와 대가

- 페이지는 고정 틀이 같은 아티팩트의 `data.json` 을 읽어 그리는 구조가 됐다. 매번 쓰는 건 JSON 하나라 HTML 이 깨질 일이 없고, 글자는 `textContent` 로만 넣어서 수집한 메시지 안의 HTML 이 실행될 여지도 없다.
- 로컬 정적 서버 + 브라우저로 4개 탭 렌더링, 체크·「안 함」 저장, 새로고침 뒤 복원을 확인했다. DB 가 없는 화면이라 브라우저 저장소 대체 경로로 확인한 것이다. 로컬에서는 charset 선언이 없어 한글이 깨졌는데, 발행할 때 껍데기가 붙여 주는 거라 테스트 사본에만 넣었다.
- 대가: 첫 실행엔 비교할 어제 값이 없어 할 일 전부가 「새로」로 간다. 스킬 문서가 102줄 늘었다.
