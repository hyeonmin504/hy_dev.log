# 2026-06-08

**요약**: 경기장 배정의 조 분할을 "대진표에 그룹 표기가 사전 설정돼 있어야만"에서 "요청의 분할 인덱스가 단독 결정"으로 바꿨다. 대진표 그룹 설정은 UI 기본값으로 격하.

대진표에 조 라벨을 표시하는 기능이 들어온 뒤, 조 분류기가 "대진표에 그룹 표기가 설정돼 있어야" 분할하도록 게이트돼 있었다. 처음 만들 때 "대진표 사전 설정 = 분할의 전제조건"이라고 묵시적으로 둔 것이다. 그런데 운영 흐름은 달랐다. 분할은 경기장을 몇 개 쓸 수 있는지 아는 **경기장 배정 시점**의 운영 결정이지, 대진표를 그릴 때 미리 정해 두는 게 아니었다.

선택지는 셋. 게이트 유지(분할이 사전 설정에 종속), 게이트 제거 + 요청의 분할 인덱스가 단독 결정, 게이트 유지 + 첫 분할 요청 때 대진표 설정을 자동으로 채움(의미가 다른 두 데이터를 자동 동기화하면 부작용이 따라온다). 두 번째로 갔다. 대진표 그룹 설정은 "권장값·UI 라벨 기본값"으로 내려가고 게이트가 아니다. 분할 좌표계는 4분할로 통일하고 BFS로 매치를 조에 배정한다. 리그는 토너먼트 트리가 없어 분할 자체가 성립하지 않으니 거부는 그대로 뒀다.

대가는 대진표 UI 표기와 실제 경기장 분할이 자동으로 일치하지 않는다는 것. 운영 가이드로 보완했고, "항상 일치해야 한다"는 요구가 나오면 되돌린다.

3월에 만든 경기장 그룹 엔티티는 이 결정으로 "요청이 말해 준 분할을 담는 그릇"으로 역할이 분명해졌다. 15개 PR을 한 번에 머지했다.
