# /promote — 일지 → 노트 승격

## 절차

1. 범위: 인자가 없으면 최근 14일 일지. 인자가 `30d`, `2026-09` 같은 형태면 그 범위.
2. 이미 승격된 것 제외: `notes/**` 의 `출처:` 줄에 적힌 일지 경로를 모은다.
3. 후보 추출. CLAUDE.md 승격 기준으로 판정한다.
   - 같은 태그가 2편 이상 → 해당 태그 묶음을 후보로
   - 한 편 안에 "처음엔 ~ 생각했는데 ~였다" 구조가 있으면 troubleshooting 후보
   - "A 대신 B를 골랐다" 구조가 있으면 decisions 후보
   - 날짜와 무관하게 참인 사실 한 문장이 있으면 til 후보
4. 후보를 표로 보여준다. **여기서 멈추고 사용자 선택을 기다린다.**

   | # | 종류 | 제목(안) | 근거 일지 | 확신 |
   |---|---|---|---|---|

5. 사용자가 번호를 고르면 그 항목만 작성.
   - 파일명: `til/주제-케밥.md` · `troubleshooting/YYYY-MM-DD-증상.md` · `decisions/NNNN-제목.md` (NNNN은 기존 최대+1, 4자리)
   - `templates/` 의 해당 템플릿 사용. `출처:` 에 근거 일지 경로를 전부 적는다.
   - 쓸 내용 없는 섹션은 지운다. 빈 섹션 금지.
6. 원본 일지는 건드리지 않는다.
7. 작성 후 `python3 scripts/build_index.py` 실행해 색인 갱신. 커밋은 하지 않는다.
