# /retro — 회고 초안

## 절차

1. 기간 결정. 인자 없음 → 이번 주(월~일). `2026-W40` → 그 주. `2026-09` → 그 달.
   주차 계산: `date -v-$(($(date +%u)-1))d +%Y-%m-%d` (월요일), `date +%G-W%V` (ISO 주차).
2. 기간 안의 `log/` 파일을 전부 읽는다. 0편이면 "일지가 없다"고 알리고 멈춘다.
3. `templates/retro.md` 형식으로 작성. 핵심은 "이번 기간의 이야기" 섹션이다. 일지 여러 편을 하나의 흐름으로 꿴다.
   - 반복 태그·반복 주제를 "승격 후보"에 적는다 (`/promote` 재료).
   - "다음 기간에 바꿔볼 것"은 **반드시 1개**. 여러 개 쓰지 않는다.
4. 파일명 `retro/YYYY-Wnn.md` 또는 `retro/YYYY-MM.md`. 이미 있으면 덮어쓰지 말고 사용자에게 묻는다.
5. 초안을 보여주고 끝. 커밋하지 않는다.
